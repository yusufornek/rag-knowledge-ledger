Paste a workspace API token to open the console. The token is kept in this tab's session storage only and sent as a bearer header to this server's own API.

No token yet?

On a fresh instance, bootstrap the first workspace and admin token from a terminal, then paste the returned token above: 

curl -s -X POST /api/v1/auth/bootstrap \
  -H 'Content-Type: application/json' \
  -d '{"email":"you@example.com","workspace_slug":"main","workspace_name":"Main"}'
